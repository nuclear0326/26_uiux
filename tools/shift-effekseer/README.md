# Effect provenance
Authored for TIME ESCAPE; no third-party sample textures used.
Tool: Effekseer 1.80.8 https://github.com/effekseer/Effekseer/releases/tag/1808
Recorder: https://effekseer.github.io/Help_Tool/en/ToolReference/record.html
Source: shift_glint.efkproj and glint.png (procedural Gaussian texture).
Recorder settings: 256x256, frames 1-90, frequency 1, single image, X count 4, Use original image.
effekseer_export.png is the unmodified Recorder output. Native DLLs/editor are not redistributed.
Runtime sheet: central 32x32 per frame, alpha unpremultiplied, packed 10 columns x 9 rows.
Java playback: 30fps, 90 frames + 6 blank frames, different phase per hotspot.

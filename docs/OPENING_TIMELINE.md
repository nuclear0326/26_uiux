# 현재 확정된 초반 진행 (v84)

## v85 수정

시작 사고 음원에서 W1 워프 소리를 제거했다. 가동음 50%, 형광등 깜빡임, 컴퓨터 전원 차단음의 시점은 유지한다. 워프 소리가 사라져 남던 무음 대기를 제거하고 7.6초에 연출을 끝낸다. 실제 과거 이동에 사용하던 별도 효과음은 변경하지 않았다.
대사와 계속 안내를 32~64px 좌우 여백 기준 왼쪽 정렬로 변경했다. VerifyDialogue 14개, VerifyFirstTravel 11개, VerifyFailedPrototype 19개 통과. 게임 실행 없이 오프스크린 이미지와 패키지를 검증했다.

1. 불이 켜진 현재 연구실에서 시작한다.
2. 상자에서 시간이동장치를 획득하고 보관함에서 사용한다.
3. 장치 가동 중 사고가 발생하고 연구실이 정전된다.
4. 시간이동은 실패한다. 현재 연구실에 그대로 남으며 과거 방은 열리지 않는다.
5. 배전함 퍼즐로 전원을 복구한다.
6. 기존 현재 퍼즐을 진행해 컴퓨터 사고 로그를 분석하고 USB에 확보한다. 작업대에서는 설계도 복원, 부품 수집, 모듈 수리, 좌표 보정을 진행한다.
7. 로그 확보와 장치 수리를 모두 완료한 뒤 보관함 장치를 사용하면 과거로 이동한다.

로그 확보와 수리 준비의 기존 수평 미션 구조는 유지한다. 두 미션이 모두 끝나야 과거 이동이 가능하다.
새 퍼즐을 추가한 것이 아니라 기존 컴퓨터 퍼즐과 데이터 복사 과정을 사고 로그 분석과 확보 과정으로 연결했다.

## 연출 및 저장

확정된 v6 혼합 음원과 조명 타이밍은 유지한다. 워프 시도 후 도착 화면을 과거가 아닌 정전된 현재로 변경했다.
실패 이후 안내 대사는 src/assets/dialogue/ko.txt의 intro.failure에서 관리한다.
ACT_START_FAILURE는 장치 고장과 실패 상태를 저장한다. 과거 방을 열지 않는다.
intro_power_on은 최초 시험 상태에서만 전원을 켠다. 실패 이후에는 PZ004의 power_restored가 필요하다.
수리 후 과거 개방은 기존 GATE001(PZ007 및 PZ011 완료)을 사용한다.
취소된 ACT_FIRST_TRAVEL은 예전 저장을 읽기 위해 남겨 두었으며 새 게임에서 실행할 수 없다. 이미 과거로 이동한 예전 저장을 강제로 초기화하지 않는다.
새 흐름을 처음부터 확인하려면 새 게임을 사용한다. 실제 게임과 EXE는 실행하지 않았다.

## 검증

VerifyFailedPrototype 19개, VerifyIntroSequence 29개, VerifyFirstTravel 11개, VerifyDialogue 14개 통과.
전원 복구 전 퍼즐 잠금, 실패 후 현재 유지, 수리 전 이동 차단, 두 미션 후 과거 이동, 저장 복원 및 예전 저장 호환을 확인했다.

# 현재 게임의 초반 진행

기준: 2026-11-26 작업 트리 / v94 배포 코드. 기획안이 아니라 현재 구현을 설명합니다.
관련 문서: [대사 편집](DIALOGUE_GUIDE.md), [미니게임 제작](MINIGAME_TEAM_GUIDE.md), [취소된 시나리오](archive/cancelled/INTRO_SEQUENCE.md).

## 시작과 사고

1. `GameState.newGame()`이 `INTRO_START`를 완료하고 불이 켜진 현재 연구실에서 시작합니다.
2. `intro.start` 대사가 끝나면 조작 도움말을 한 번 표시합니다. 이후에는 ? 버튼으로 다시 볼 수 있습니다.
3. 왼쪽 보관 상자에서 장치를 획득합니다(`TUT001`, `DEVICE`). 첫 시험 전 Shift는 미획득 상자만 강조합니다.
4. 보관함의 장치를 사용하면 가동음과 조명 깜빡임, 전원 차단 연출이 진행됩니다.
5. 시간이동은 실패합니다. 현재에 남으며 `ACT_START_FAILURE`로 고장·실패 상태를 기록합니다. 이 사건은 과거 방을 열지 않습니다.
6. 연출 완료 후 `intro.failure` 안내와 함께 전력 복구를 진행합니다.

## 전력 복구 후 로그 분석과 수리

`PZ004`는 현재 배전함의 배선 연결 퍼즐입니다. 쉬움과 어려움을 모두 완료해야 `power_restored`가 기록됩니다.

| 미션 | 현재 구현 순서 | 완료 기준 |
|---|---|---|
| 로그 확보 `M_USB` | 메모 획득 `ACT_GET_CIPHER` → PC 암호 `PZ006` → Rush Hour `PZ001` → USB 복사 `PZ007` → 사고 로그 분석 `PZ021` | `PZ021` 완료 |
| 장치 수리 `M_DEVICE` | 설계도 복원 `PZ008` → 부품 수집 `PZ009` → 모듈 수리 `PZ010` → 시간 좌표 보정 `PZ011` | `PZ011` 완료 |

사고 로그 분석을 완료해야 작업대의 설계도 복원부터 장치 수리를 시작할 수 있습니다. 제작 부품 3종은 사고 로그 분석 완료 후부터 수집할 수 있습니다. 이전 저장에 이미 보유한 부품은 유지하며, 이전 형식에서 설계도 복원을 끝낸 수리 진행도도 이어집니다.
USB는 서랍에서 얻는 빈 USB가 먼저 필요합니다. 현재 `PZ007`은 USB 보유 조건을 확인한 뒤 복사 확인 창으로 진행하며, 별도의 새 미니게임이 아닙니다.
로그 분석과 장치 수리 완료 후 자동 단계 `GATE001`이 `past_1`을 개방합니다. 보관함의 장치를 사용해 과거로 이동합니다.

## 현재 적용된 사고 연출

`FirstTravelOverlay`의 이름은 예전 구현에서 유지된 이름입니다. 현재는 과거 배경이나 워프음을 재생하지 않습니다.

| 시각 | 동작 |
|---|---|
| 0.6716초 | 조명 깜빡임 시작 |
| 4.5716초 | 전원 차단음 기준 시각 |
| 4.6716초 | 완전 소등 |
| 5.9216초 | 내부 도착 콜백 기준 시각. 실제 시대 이동을 뜻하지 않음 |
| 7.6초 | 연출 종료 |

원본 가동음에 적용한 50% 편집과 별개로, 게임 설정의 효과음 슬라이더가 최종 재생 음량에 적용됩니다.
음원의 재생 위치로 연출을 맞추며 오디오가 준비되지 않거나 멈추면 무음 진행으로 전환할 수 있습니다.
배경은 일반 게임 화면과 같은 `SceneViewport.cover`를 사용합니다. 과거 시안의 확대·잔상·색 번짐은 현재 구현 기준이 아닙니다.

## 과거 이후와 저장 호환

- 과거 톱니바퀴 `PZ002` → 대체 부품 `SPARE` → `ACT_REPAIR`에서 소비·수리 → `GATE002`로 미래 개방.
- 미래 `PZ003`은 기존 전력 합계 퍼즐을 옮긴 **전원 켜기 (임시)**입니다. 현재 배전함과 다른 구현입니다.
- 취소된 `ACT_FIRST_TRAVEL`은 예전 저장 복원 호환을 위해 남아 있으며 새 실행은 차단합니다.
- 배포 버전별 세이브 위치는 `SaveStore`에서 분리합니다. 새 버전의 빈 저장소를 위해 기존 버전의 저장 파일을 삭제하지 않습니다.
- 초기 사고 전 `intro_power_on`과 사고 이후 `power_restored`는 다른 상태입니다. 새 게임의 켜진 배경을 전력 퍼즐 완료로 취급하지 않습니다.

이 문서는 소스와 진행 설정을 대조해 갱신했습니다. 게임 실행 검증은 수행하지 않았습니다.

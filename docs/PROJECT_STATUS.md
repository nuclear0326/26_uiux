# 현재 진행상황

확인일: 2026-11-26. 기준: 현재 작업 트리와 v92 배포 구성.
기획 목표와 실제 구현을 구분하며, 이 문서는 이번 코드 대조 결과입니다.

## 현재 플레이 흐름

켜진 현재 연구실 → 시작 대사와 도움말 → 상자에서 장치 획득 → 보관함에서 사용 → 작동 실패·정전 → 배선 퍼즐로 전력 복구 → 로그 확보와 장치 수리 두 병렬 미션 → 과거 개방·이동 → 톱니바퀴 수리와 대체 부품 장착 → 미래 개방 → 임시 전력 합계 퍼즐 → 핵심 부품 장착·탈출 완료.

첫 사용에서 과거로 잘못 이동하던 흐름은 취소되었습니다. [현재 타임라인](OPENING_TIMELINE.md)을 기준으로 개발합니다.

## 구현되어 있는 기능

| 영역 | 현재 상태 |
|---|---|
| 퍼즐 | 현재 배선 쉬움·어려움, 메모 해독, Rush Hour, 설계도·모듈·좌표 퍼즐, 과거 4×4 톱니바퀴, 미래 전력 합계 임시 퍼즐 |
| 진행 | 고유 ID 기반 완료·보상·소비·환경 상태·방 개방, 병렬 미션 조건 |
| 튜토리얼 | 장치 획득·사용 안내, 첫 안내 후 도움말, 시작 실패 대사 |
| 연구 노트 | 연구 기록·보관함 전환, 종이 질감, 전체 페이지 넘김, 화면 크기 대응 |
| 아이템 | 획득 알림, 미확인 빨간 점, 마우스 확인 상태의 저장 |
| Shift | 완료 오브젝트 제외, 당장 가능한 대상 강조, 이후 대상의 조명 구분 |
| 메뉴 | 저장·불러오기·설정·메인 메뉴, 도움말, Esc 열기·닫기 |
| 저장 | 자동 1개·수동 4개, 종료 후 복원, 버전별 저장 폴더 |
| 사운드 설정 | 배경음악·환경음·효과음 분리 슬라이더, 별도 설정 파일에 영속 저장 |
| 연출 | 시작 메뉴의 비·번개·시계·소등·균열, 현재 창문 날씨, 사고 소등과 음원 시계 연동 |
| 구조 | 공통 PuzzleRunner/PuzzleResult, 독립 모델·패널, 비동기 오디오와 저장, 날씨 데이터 사전 생성 |

현재 USB 복사는 보유 아이템 조건과 확인 창으로 처리합니다. 별도의 신규 미니게임으로 구현된 것은 아닙니다.
미니게임은 장식 없는 모달 창이며, 미니게임 중 메인 창 크기 조절을 지원하는 변경은 적용하지 않았습니다.

## 후속 개발 및 정리 대상

- 미래의 `전원 켜기 (임시)`를 확정 기믹으로 교체.
- 추가 방·숨겨진 방, 열린 방의 양방향 재방문, 시대를 오가는 아이템 연계 확장.
- 총 20분 이상 플레이 목표에 맞춘 콘텐츠·난이도 검증. 현재 플레이타임을 달성했다고 확인한 상태는 아님.
- 로고 확정과 TIME ESCAPE 텍스트 교체.
- 개발용 Shift+8+9+0 스킵을 정식 배포 전에 비활성화하고 검증.
- 타임어택은 현재 구현 범위에서 제외.

위 항목은 후속 작업이며 이번 문서 정리에서 게임 기능을 추가하지 않았습니다.

## 개발 파일과 배포 상태

- Git 관리: src, tools, docs, test, design. bin은 Eclipse 로컬 컴파일 결과로 제외.
- 빌드: 저장소 옆 `26_uiux_artifacts/build`, 성공한 최신 버전 유지.
- 배포·미리보기: `26_uiux_artifacts/outputs`, 기존 배포본 보존.
- 현재 배포: `uix_v92_windows/TimeEscape/TimeEscape.exe`, `TIME_ESCAPE_v92_Windows.zip`.
- 제작 도구는 `tools/authoring`, Effekseer 원본은 `design/effects/shift-effekseer`.
- 음원 초안은 새 외부 폴더에 생성하며 현재 게임 음원을 자동 덮어쓰지 않음.

[빌드 안내](../tools/ARTIFACTS.md), [저장 정책](SAVE_GUIDE.md), [테스트 안내](../test/README.md).

## 검증 기록의 범위

앞선 정리 작업에서 전체 Java 소스 컴파일, 선택한 회귀 검증 33개, 자동 정리 및 음원 제작 안전성 검사, 실제 빌드·패키징 무결성을 확인했습니다.
이는 각 검증이 수행된 시점의 결과이며 모든 도구·보관 테스트를 실행했다는 뜻은 아닙니다.
이번 문서 작업에서는 코드와 문서 링크만 대조했고 게임·EXE·오디오는 실행하지 않았습니다.
새로운 수동 플레이, 물리 장치 음질 확인, 플레이타임 측정은 수행하지 않았습니다.

과거 기록은 [보관 문서](archive/README.md)에 있습니다.

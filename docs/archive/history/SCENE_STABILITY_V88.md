# v88 배경 흔들림 수정 및 검증

2026-11-25

일반 연구실과 사고 연출이 SceneViewport.cover를 공유한다. 원본 1920x1080 좌표계의 비율을 유지하고 중앙을 기준으로 잘라낸다. 기존 사고 연출의 확대, 중첩 잔상, 워프 색상 덮개는 제거했다. 조명 밝기 타임라인, 오디오, 완료 콜백 시점과 저장 데이터 형식은 유지한다. 초기 사고에 불필요한 과거 배경 로딩도 제거했다.

## 자동 검증
- Java 21 컴파일 성공.
- VerifySceneStability: 5개 화면 크기(1484x775, 1280x720, 1024x768, 1920x1014, 2560x1080), 9개 시점의 배경 픽셀 비교 45개 통과.
- VerifyFirstTravel: 완료 1회 호출, 입력 차단, 취소, 저장 포함 11개 통과.
- VerifyFailedPrototype: 정전, 로그, 수리, 이동 및 기존 저장 호환성 19개 통과.
- ZIP/JAR 무결성 검사 통과.

## 실제 EXE 검증
별도 저장 경로로 패키징한 v88과 동일한 JAR/런타임을 실행했다. 새 게임 시작, 대사 진행, 상자에서 장치 획득, 연구 노트 보관함에서 사용, 정전 연출, 사고 후 대사까지 직접 진행했다.
1486x873 창의 상단 바 아래 연구실에서 연출 진입, 소등 중, 종료 후 시계와 창틀 위치를 비교했다. v87에서 재현된 세로 위치 변화와 확대 복귀가 관찰되지 않았다. 이후 진행 전체를 완주한 검증은 아니며, 다른 화면 비율은 자동 렌더링 검사로 확인했다. 사용자 저장소는 사용하지 않았다.

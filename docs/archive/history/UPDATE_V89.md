# v89 퍼즐 배치와 첫 실행 안내

- 현재 배전함 POWER / 진행 ID PZ004: 전선 연결 퍼즐. 쉬움 이후 어려움을 완료해야 전력 복구와 자동저장 처리.
- 미래 장치 FUTURE_CORE / 진행 ID PZ003: 기존 스위치 합계 16 퍼즐을 전원 켜기 (임시)로 이동. 완료 보상 CORE와 후속 진행은 기존 PZ003 규칙 유지.
- 진행 ID는 위치별 보상과 조건의 식별자다. 미래 임시 퍼즐은 기존 PZ004 모델을 재사용하지만 완료 처리는 실행 관리자가 PZ003에 적용한다.
- 새 게임 첫 대사 종료 후 조작 도움말 자동 표시. 일반 대사 및 이어하기에는 자동 표시하지 않는다. ? 버튼 안내를 도움말 제목 아래에 추가.
- Windows 패키지 저장 경로: %LOCALAPPDATA%/TimeEscape/save/v89.0. 이후 빌드 버전마다 별도 경로로 시작한다. 같은 버전은 계속 저장 및 이어하기 가능. 이전 저장 파일은 삭제하지 않는다. 개발 실행 및 명시적인 timeescape.saveDir는 기존 방식 유지.
- 배포 ZIP에 save 폴더 및 .save 파일을 포함하지 않도록 패키징 필터 추가.

검증: Java 21 컴파일, 변경사항 13개, 도움말 레이아웃 및 입력 43개, 사고 흐름 19개, 저장 및 복구 45개, 슬롯 20개 검사 통과. 퍼즐 실행 등록도 전체 확인. 화면은 실제 UI의 오프스크린 렌더링으로 확인했으며 게임 EXE는 실행하지 않았다.

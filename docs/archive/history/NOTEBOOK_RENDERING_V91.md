# v91 연구 노트 렌더링과 반응형 크기

## 원인 분석
전환 시 다른 폰트로 교체하지 않는다. TurningNotebook.capture가 논리 픽셀 수만큼 이미지로 캡처해 HiDPI 화면에서 확대되므로 실시간 Swing 글씨와 선명도가 달라질 수 있었다. 캡처와 실제 화면의 렌더링 경로도 달랐다.

## 수정
- 전환 이미지에 GraphicsConfiguration의 화면 DPI 배율을 적용하고 논리 영역에 맞춰 표시한다.
- 실시간 및 전환용 렌더링에 동일한 글자 안티앨리어싱 설정을 적용한다.
- 닫기 버튼은 배경과 테두리가 없는 굵은 선 두 개의 X 아이콘이다.
- 연구실 표시 영역의 1440x755 기준 배율을 사용한다. 가로/세로 비율 중 작은 배율을 택해 노트 비율을 유지한다. 최소 배율은 0.65이다.
- 제목/탭/본문/아이템 그림/행 높이/여백을 함께 변경한다. 실제 Swing 컴포넌트 크기를 변경하므로 클릭 좌표는 별도 보정 없이 유지된다.
- 크기 변경 중에는 이전 크기의 페이지 전환 캡처를 즉시 폐기한다.

## 검증
- 신규 배율/폰트 유지/2배 DPI 캡처/닫기/아이템 클릭/크기 변경/누적 배율 방지 38개 통과.
- 기존 노트/진행 상태/클릭 영역 회귀 검사 48개 통과.
- 튜토리얼과 도움말 연결 등 v89 회귀 검사 13개 통과.
- 1020x650, 1440x821, 1920x1080, 2560x1440 화면을 오프스크린으로 생성했다. 작은 화면과 큰 화면의 레이아웃을 시각 확인했다.
- EXE를 실행한 검증은 하지 않았다. 실제 모니터별 DPI 이동 동작은 자동화된 캡처 배율 검사로 대체했다.

# v90 대체 부품 장착 오류 수정

원인: GameState.available에서 INTRO_START가 있는 모든 새 게임의 ACT_REPAIR와 GATE002를 차단했다. DeviceDialog는 부품 보유와 선택 여부만 검사해 실제 실행이 거부되는 버튼을 활성화했다.

변경: 폐기된 과거 직행 시나리오에만 기존 제한을 유지하고, 현재 사고 후 수리하여 과거에 도착한 경로는 카탈로그의 선행 퍼즐과 부품 조건으로 처리한다. 장착 버튼은 ACT_REPAIR의 실제 실행 가능 여부를 사용하고 미래 이동 버튼은 목적지 개방을 확인한다. 장착 후 안내가 과거 도착 메시지에 가려지지 않게 하고, 보관함도 수리 완료 후 고장 문구를 표시하지 않는다.

검증: Java 21 컴파일, 대체 부품 및 선행 조건/중복 장착/저장 복원/미래 이동/핵심 부품/최종 완료 12개 검사 통과. 기존 사고 흐름 19개, v89 퍼즐 및 도움말 흐름 13개 검사 통과. 게임 창은 실행하지 않고 진행 로직과 UI 연결 코드를 검증했다.

저장 정책: 요청한 버전별 초기 시작 정책에 따라 v90.0 저장소를 사용한다. 기존 v89 저장 파일은 변경하거나 삭제하지 않는다. 저장 형식 자체는 호환된다.

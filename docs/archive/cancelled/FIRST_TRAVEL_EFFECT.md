## 구현

FirstTravelOverlay는 배경 확대, 잔상 및 색 번짐을 Swing에서 렌더링한다. 영상이나 GIF를 게임에 넣지 않는다.
first_travel.wav는 확정된 시안의 soundtrack.wav와 바이트 단위로 같다. 음원 하나의 재생 위치를 화면 시계로 사용한다.
오디오와 배경 준비는 작업 스레드에서 진행한다. 음원 준비 중에는 첫 화면을 유지한다. 장치 오류, 재생 정지, 5초 초과 준비 지연 시 무음 타임라인으로 완료 가능하다.
연출 중에는 배경음과 별도 효과음을 억제하며 메뉴, 노트 및 오브젝트 입력을 막는다.
진행 데이터는 영상상 도착 직후가 아니라 마지막 음원 여운이 끝난 뒤 한 번 확정한다. 종료하거나 창이 제거되면 콜백과 늦게 준비된 오디오를 취소한다. 연출 중 게임 종료는 이동 전 상태를 저장한다.
새 시나리오의 최초 장치 사용에만 적용하며 기존 저장의 이동 경로와 퍼즐 보상 규칙은 유지한다.

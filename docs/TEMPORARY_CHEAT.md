# 임시 미니게임 단계 스킵

기준: 2026-11-26 / `DeveloperMode`와 각 퍼즐 패널. [미니게임 가이드](MINIGAME_TEAM_GUIDE.md).

미니게임 창에서 Shift를 누른 채 8, 9, 0을 모두 누릅니다. 숫자를 누르는 순서는 무관합니다. 숫자패드도 지원합니다.

일반 퍼즐은 완료합니다. 배선 퍼즐은 첫 입력에 쉬움에서 어려움으로 이동하고, 숫자 키를 모두 떼었다가 다시 입력하면 완료합니다. 누르고 있는 동안 중복 실행하지 않습니다.

Ctrl+Shift+F10 연결은 제거했습니다. 별도 개발 모드 설정은 필요 없습니다. 일반 정답 판정과 완료 함수는 유지합니다. 최종 완료 시에만 기존 보상과 저장 처리가 이어집니다.

정식 배포 전에 DeveloperMode.TEMPORARY_PUZZLE_CHEAT를 false로 바꾸고 재빌드합니다.

게임과 EXE를 실행하지 않고 키 입력, 단계 전환, 일반 풀이 완료, 저장을 검증했습니다.

현재 배선 퍼즐은 현재 연구실의 배전함에 배치되어 있습니다. 첫 스킵은 어려움으로 전환만 하며, 두 번째 스킵에서 최종 완료·보상·자동저장이 처리됩니다. 메인 게임 화면의 Esc 메뉴와 미니게임 창의 Esc 취소는 별도 동작입니다.

# TIME ESCAPE v43

Windows ZIP 전체를 압축 해제하고 TimeEscape/TimeEscape.exe를 실행하세요.
EXE 옆의 app 및 runtime 폴더를 함께 유지해야 합니다. Java 별도 설치는 필요 없습니다.

## 연구 노트 인터페이스
- 상단: 연구 노트 / ? 조작 도움말 / 햄버거 메뉴(메인 메뉴, 설정, 초기화).
- 연구 노트는 버튼으로 열고 닫습니다. × 또는 Esc로도 닫습니다.
- 밝은 종이, 스프링 없는 좁은 패널. 연구 기록 / 보관함 탭 전환.
- 현재 목표 및 두 병렬 미션의 실제 진행도 표시.
- 보관함은 실제 보유 아이템만 그림 왼쪽 / 설명 오른쪽의 세로 목록으로 표시합니다.
- 아이템 행 클릭으로 기존 부품 선택 및 손목 장치 사용 기능을 이용합니다.
- 하단 상시 안내 제거. 상호작용 결과는 잠시 표시되고 연구 기록의 최근 기록에도 남습니다.
- 배경은 화면에 가득 차게 비율을 유지하여 표시합니다. 창 비율에 따라 가장자리 일부가 잘릴 수 있습니다.

기존 퍼즐, 미션 조건, 시작 연출, 빗방울·번개·효과음, Shift 표시 유지.
제목 Noto Serif KR SemiBold / 본문 Pretendard Regular / 버튼 Pretendard SemiBold.
폰트 OFL 라이선스 포함.

게임 창이나 EXE를 실행하지 않고 컴파일·헤드리스 UI 렌더링·로직 검사·배포 파일 검증을 수행했습니다.

## v42 시각 개선
- 낡은 종이 질감, 가장자리 마모와 음영, 실사 기반 아이템 그림.
- 연구 기록 / 보관함 전환 시 제목·탭·본문·테두리를 포함한 전체 종이가 약 0.46초 동안 넘어갑니다.
- 역방향 전환 지원. 넘기는 동안 아이템 오입력 차단, 닫기/연속 전환 시 타이머 정리.
- 애니메이션은 Java2D로 실시간 그립니다. 미리보기 GIF를 게임에서 재생하지 않습니다.

## v43 게임 메뉴
- 중앙의 반투명 검정 패널. 연구실은 부드럽게 흐려지며 패널 뒤로 희미하게 비칩니다.
- 게임 메뉴: 메인 메뉴 / 설정 / 초기화. 글씨만 있는 메뉴와 닫기 ×.
- 설정: 기존 시작 연출(소등·시계 파손) 켜기/끄기. 현재 세션에 적용됩니다.
- 초기화: 확인 후 현재 진행을 처음부터 재시작. 취소 시 진행 유지.
- Esc: 하위 화면에서는 게임 메뉴로 돌아가고, 게임 메뉴에서는 닫기.
- 메뉴가 열린 동안 배경 오브젝트 클릭과 Shift 입력을 차단합니다.

## v44 진행 구조 정리
- Rush Hour 초기화/닫기 시 완료 예약 취소 및 중복 보상 방지.
- 진행 정의는 src/assets/progression/game.properties로 분리.
- 상세 확장 방법과 현재 구현 범위는 PROGRESSION.md 참조.
- 기존 디자인과 플레이 흐름 유지. 디스크 저장/재방문 UI는 이번 범위에 포함하지 않음.

## v45 파일 저장·이어하기
- 진행 변경 시 자동 저장, 종료 후 이어하기 지원.
- 완료 단계·아이템·현재/열린 방·환경 변경 상태를 함께 저장합니다.
- 기본 위치: %LOCALAPPDATA%/TimeEscape/save/progress.save
- 백업 복구와 새 게임 초기화 확인 지원. 기존 디자인 유지.
- 자세한 내용: SAVE_GUIDE.md

## v46 자동저장·수동 저장소
- 게임 메뉴에 저장 추가. 자동저장을 상단에 표시하고 수동 저장소 1·2 제공.
- 이어하기에서 저장소를 선택해 불러옵니다. 기존 v45 저장 호환.
- 새 게임/초기화는 자동저장만 초기화하며 수동 저장은 유지합니다.
- 위치·완료 퍼즐 수·저장 시간, 덮어쓰기 확인 및 슬롯별 백업 지원.
- 자세한 내용은 SAVE_GUIDE.md 참조.

## v47 저장소 확장
- 자동저장 + 수동 저장소 1~4. 기존 세이브 유지.
- 작은 화면에서도 다섯 슬롯이 표시되도록 저장/이어하기 패널 높이 조정.

## v48 저장 화면 디자인

- 돌아가기 글씨를 Java2D 곡선 화살표로 변경. 툴팁/접근성 이름과 동작 유지.

## v50 도움말과 상단 표기
- ? 도움말을 기존 메뉴와 같은 어두운 반투명 창으로 변경.
- 진행 안내 설명 가운데 정렬. 닫기/×/Esc 지원, 배경 클릭 및 Shift 차단.
- TIME ESCAPE 유지, 시간: 현재 | 장소: 연구실 형태로 동적 표시.
- 상단 디자인 대안은 별도 제안이며 배포본에는 적용하지 않음.

- 두 항목 간격 50px. TIME ESCAPE의 글씨/스타일/왼쪽 배치는 유지.
- 승인된 화면과 같은 빌드를 Windows 패키지에 포함합니다. 게임 미실행.

## v53 새 게임 확인창
작은 반투명 메뉴 스타일로 통일. 시작/취소 글씨형 버튼과 ×/Esc 닫기. 자동저장 초기화와 수동 저장소 1~4 유지 안내. 확인 후 기존 시작 연출 유지.

## v54
게임 메뉴: 저장 → 불러오기 → 설정 → 메인 메뉴. 인게임 불러오기에서 자동저장과 수동 저장소 1~4를 복원합니다.

## v56
빌드 스크립트가 빗방울과 번개 데이터를 자동으로 생성합니다. 개발 도구 실행에는 JDK 21이 필요합니다. 승인된 연출과 기존 저장 형식은 유지됩니다. 측정 조건과 결과는 TEST_REPORT.md를 참고하세요.

## v57
오디오 초기화는 전용 스레드에서 처리합니다. 음원과 연출 타이밍은 유지하며, 시작 소리가 준비되기 전에는 연출 시간만 보류합니다. 상세 검증은 TEST_REPORT.md를 참고하세요.

## v58
저장·불러오기·저장소 조회는 전용 스레드에서 처리합니다. 기존 저장 데이터는 그대로 사용합니다. 검증 결과는 TEST_REPORT.md를 참고하세요.

## v59
미니게임 실행 등록은 PuzzleDialogs, 완료 검증 및 반영은 PuzzleRunner에서 담당합니다. 모든 미니게임은 PuzzleResult를 반환하며 진행 데이터를 직접 수정하지 않습니다. 기존 저장 파일은 변환 없이 사용할 수 있습니다. 상세 검증은 TEST_REPORT.md를 참고하세요.

## v60
GearsPuzzlePanel과 WiresPuzzlePanel은 독립 모델/입력을 소유합니다. RepairPuzzlePanel은 공통 배치·완료 콜백, RepairPuzzleDialog는 공통 창을 담당합니다. 새 수리 퍼즐 패널은 공통 창의 PanelFactory로 연결할 수 있습니다. TEST_REPORT.md에 검증을 기록했습니다.

## v61
현재 퍼즐의 규칙은 puzzle/present 아래 개별 모델에 있습니다. PresentPuzzle이 공통 계약, PresentPuzzles가 생성 등록표입니다. 순환 조작은 CyclicValuesPuzzle을 재사용할 수 있습니다. UI는 새 인터페이스를 사용하며 이전 PresentPuzzleModel은 위임 어댑터입니다. TEST_REPORT.md에 비교 검증을 기록했습니다.

# 디자인 제작 자료

- [효과 원본](effects/shift-effekseer/README.md): Effekseer 프로젝트, 텍스처, 원본 출력 시트.
- [커서 승인 시안](cursors/blue-yellow-approved.png): 편집·비교를 위한 참고 이미지.

게임은 이 폴더를 직접 읽지 않습니다. 적용 자산은 `src/assets`에 있습니다.
Shift 효과의 실제 재생 시트는 `src/assets/effects/shift_glint.png`, 커서는 `src/assets/cursors/normal.png`와 `interact.png`입니다.
효과 프로젝트와 glint.png는 상대 참조를 유지하도록 같은 폴더에 보관합니다.
빌드와 배포에 포함되는 것은 적용 자산이며 제작 프로젝트나 편집기는 포함하지 않습니다.
